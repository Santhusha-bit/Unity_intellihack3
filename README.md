# Preg-Ma project

## 🚀 Project Overview

**Preg-Ma** is a health-focused predictive web application designed to assist in early detection of conditions like diabetes and breast cancer using machine learning. It integrates a user-friendly web interface with a powerful backend model for real-time predictions and visualizations.

### Running the Project

Clone the repository from github.

```sh
git clone https://github.com/Santhusha-bit/Unity_intellihack3.git
```

Development 

1. Go to `webapp/streamlit` directory and run this command
```sh
$ cd webapp/streamlit
$ streamlit run Home.py
```
